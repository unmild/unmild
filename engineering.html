Working with the tools

Understand the boundaries.

Review before you rely on it.

Inspect generated code and manufacturing files before use. Product outputs are part of a workflow that still needs your judgment and verification.

Know what the workflow needs.

Designer’s Mool workflow requires a matching local toolchain. Agent requires a supported provider API key, with usage billed by that provider. Product documentation has the setup details.
